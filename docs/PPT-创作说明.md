# 论文云 · PPT 创作说明（交给另一台机器的 AI 执行）

> 这份文档是**创作任务书**，不是大纲。目标是让另一个 AI 拿到它能**直接产出 14 页 pptx**，
> 且做到：科幻感、磅礴感、elegant、艺术感。所有需要判断的地方都给了明确约束和禁止项。

---

## 0 一句话定位

**「三百万篇论文，一座可漫游的宇宙。」**
把 arXiv 3,052,327 篇论文按 8 个学科放进一座三维星系；每颗星是一篇论文，
点开一颗星，它就亮起并牵出它引用过的论文。**这不是数据可视化，是一次宇宙尺度的凝视。**

- 观众：实验室 PI、基金评审、学术会议 keynotes、潜在合作者
- 时长：12–15 分钟讲演（14 页）
- 情绪曲线：**静（宇宙）→ 惊（三百万）→ 近（一颗星）→ 悟（引用即星轨）→ 远（人类知识地形）**

---

## 1 视觉语言（硬约束，不许跑偏）

### 1.1 三个词落地成规则

| 要求 | 具体做法 |
|---|---|
| **科幻感** | 纯黑底 `#04050A`；发光只靠"加法叠加"（粒子越多越亮，不描边、不加阴影）；可选极淡扫描线/星尘噪点（不透明度 ≤ 0.03） |
| **磅礴感** | 强对比：**96% 的画面是黑的**，只有星与文字在发光；数字用超大字号（占屏宽 40%+）；大量留白（每页文字 ≤ 40 字） |
| **elegant / 艺术感** | 细字重（Light 300）+ 大字距（标题 0.02em、正文 0.01em）；单一冷色点缀（青 `#00E0A8`）+ 单一暖色点睛（琥珀 `#FFB350`），**不超过两色**；曲线只用来做"星轨"，不做装饰框 |

### 1.2 配色（只许用这几个）

```
背景   #04050A   接近纯黑，不是 #000（留出辉光空间）
主文字 #F2F5FF   冷白
次文字 #8C97B0   60% 亮度的冷灰蓝
强调1  #00E0A8   青绿（学科色之一，代表"数据/生命"）
强调2  #FFB350   琥珀（学科色之一，代表"恒星/热"）
禁用   任何紫色渐变、任何毛玻璃卡片、任何彩色圆角按钮
```

### 1.3 字体

- 中文：思源黑体 / 苹方（Light 300、Regular 400 两种字重，**不用 Bold**）
- 英文/数字：**JetBrains Mono** 或 IBM Plex Mono（数字必须是等宽，这是"科学仪表盘"的语感）
- 单页最多两种字号；标题 : 正文 ≈ **3 : 1**

### 1.4 动画（关键！）

- 入场：**只做"淡入 + 极缓放大"**（scale 0.98 → 1.00，600ms，ease-out），**禁止**飞入、弹跳、旋转
- 星空页：允许粒子缓慢漂移（每帧位移 < 0.3px，观众应"几乎察觉不到但在动"）
- 数字页：数字从 0 快速滚动到目标值（800ms），滚动结束**停留 1 秒不加任何效果**
- 转场：**只有一种**——黑场淡入淡出（400ms）。禁止任何 3D 翻转、百叶窗

## 2 叙事结构（14 页，逐页执行）

### P1 封面
- 画面：满屏星尘（取项目截图 `shots/papercloud.png` 做背景，压暗到 35% 亮度）
- 文字（居中偏上，字号：标题 72pt / 副标题 20pt）：
  - 主：**论文云**
  - 副：PAPER CLOUD · 三百万篇论文的星系
- 右下角极小字（10pt，次文字色）：`3,052,327 papers · 8 disciplines · 1,622,466 points`

### P2 静默
- 黑场，只有一行字（居中，28pt，字距 0.3em）：
  > 「人类写下的论文，已经多到没有人能读完了。」
- **整页停留 4 秒**，无任何动画。

### P3 数字撞击
- 三个数字纵向排列，左对齐，等宽字体：
  - `3,052,327`（96pt，冷白）  **篇论文**
  - `8`（96pt，青）  **个学科**
  - `0`（96pt，琥珀）  **个人读得完**
- 数字滚动动画；下方一行 14pt 次文字：`arXiv 全量元数据，2026`

### P4 它不是表格
- 左侧 55%：项目默认视图截图（八个星团）
- 右侧 45%：三行文字（24pt，行距 1.8）
  - 每篇论文 → 一颗星
  - 位置由语义关系算出
  - 颜色 = 学科
- 底部 12pt：`没有坐标轴，没有柱状图。只有引力与光。`

### P5 八个星系
- 网格 2×4，每格：学科色圆点（12px）+ 学科名（18pt）+ 论文数（等宽 14pt，次文字色）
- 八个学科：物理 1,463,588 / 计算机 886,174 / 数学 575,978 / 电子工程 81,561 / 统计 64,641 / 生物 34,356 / 金融 13,543 / 经济 12,486
- 每格出现间隔 80ms（不要同时出现）

### P6 一颗星的自白
- 全屏近景：单颗星特写（放大到占屏 8%）
- 旁边浮出标题（20pt，最多两行）：`Ultrafast Melting of Spin Density Wave Order in BaFe₂(As₀.₇P₀.₃)₂ …`
- 下方（14pt，次文字）：2023 · Phys. Rev. · 被引 71
- 一句话（24pt，琥珀）：**「点它之前，它只是星空的一部分。」**

### P7 引用就是星轨
- 画面：点开后的扇形连线截图（`shots/first.png` 或重截）
- 三条注释线（细，0.5px，次文字色）指向：中心星 / 库内引用 / 库外引用
- 文案（20pt）：**「每一次引用，都是两颗粒子之间的一次引力。」**

### P8 数据是真的
- 左侧：一句大字（32pt）`不是示意图。`（琥珀）
- 右侧：四行等宽小字（14pt），每行一条实测：
  - `3,052,327  篇元数据`
  - `1,622,466  个三维点`
  - `physics.bin  5.9 MB 静态引用表`
  - `引用接口  平均 1.5 s / 篇（OpenAlex 兜底）`
- 底部 12pt：`所有数字来自 2026-10-19 实测，见仓库 docs/现状-2026-10-19.md`

### P9 技术诗
- 全黑，只有四行代码风文字（JetBrains Mono 16pt，逐行出现）：
  ```
  position  = sampleAddress(paper.address)   // 学术关系 → 三维坐标
  color     = domain.color                   // 学科 → 颜色
  brightness= log(1 + citationCount)         // 被引 → 亮度
  size      = 1.1 + 5.5 · t²                 // 被引 → 星等
  ```
- 每行是"物理公式"的排版：左对齐，等号对齐

### P10 交互
- 三栏（等宽），每栏：小标题（16pt 青）+ 一句说明（18pt）
  - **悬停** · 浮现论文名
  - **点击** · 亮起并牵出引用
  - **飞行** · WASD 穿过星系
- 底部 12pt 次文字：`没有菜单，没有侧边栏。宇宙本身就是界面。`

### P11 它为什么重要
- 一句话居中（36pt，冷白，两行）：
  > 「当你无法读完所有论文，你至少可以**看见**它们的形状。」
- 下方 18pt 次文字，三行：
  - 学科之间的空白，是还没人做过的交叉
  - 孤立的小星团，是被忽略的方向
  - 最亮的那些点，是全人类的注意力

### P12 边界（诚实）
- 标题（24pt）：`它不是什么`
- 三条（20pt，次文字色）：
  - 不是文献检索工具
  - 不是引文分析报告
  - 不是"AI 帮你读完论文"
- 一句（24pt，琥珀）：**「它只是让你第一次看见全貌。」**

### P13 演化
- 时间轴（细线 0.5px，三个节点）：
  - `2026.10  三维星系 + 静态引用表`
  - `下一步  全库被引次数 + 库内引用反查`
  - `再下一步  实时共被引网络`
- 排版：横向，节点用 8px 圆点，只有已完成的节点是青，未完成是次文字色

### P14 收尾
- 与 P1 同构图（星空背景），文字：
  - 主（48pt）：**去点一颗星。**
  - 副（18pt，次文字）：`http://127.0.0.1:5311`
- 停留 5 秒，黑场淡出。

## 3 资产清单（用仓库里现成的）

| 用途 | 文件 |
|---|---|
| 默认视图（八团） | `shots/papercloud.png` |
| 点开状态（引用扇形） | `shots/first.png` |
| 学院色 | `src/data/domains.ts` 里的 8 个 `color` |
| 真实数据 | `docs/现状-2026-10-19.md` |

> 若截图不可用：让 AI **不要自己画星空**，改用纯黑 + 极简文字版（宁可素，不可假）。
> 禁止用 AI 生成"假星空插画"——那会立刻毁掉"这是真实数据"的说服力。

---

## 4 交付要求

1. 16:9，`.pptx`，14 页，用 `python-pptx` 生成（不要手工排版）
2. **每页文字 ≤ 40 字**（数字不算）
3. 全篇只有两种字号体系、两种颜色、一种动画节奏
4. 附一份 `speaker-notes.md`：每页 2–3 句讲稿（口语、不念稿）
5. 自检清单（生成后逐条打勾）：
   - [ ] 背景是 `#04050A` 而不是纯黑
   - [ ] 没有任何渐变、阴影、圆角卡片
   - [ ] 数字全部等宽字体
   - [ ] 每页文字 ≤ 40 字
   - [ ] 转场只有黑场淡入淡出
   - [ ] 至少 4 页是"一句话 + 大片黑"

---

## 5 禁止项（违反任何一条就重做）

- ❌ 蓝紫科技渐变、发光网格、粒子背景模板
- ❌ "赋能/闭环/抓手/生态"这类词
- ❌ 每页都塞满字的 bullet list
- ❌ 用 emoji 当图标
- ❌ 虚假数据、编造的引用数
- ❌ 把项目说成"AI 论文阅读器"

---

## 6 一句话校验

做完之后自己读一遍：**如果这份 PPT 让别人觉得"这就是一张星空图"，就对了；
如果让人觉得"这是一个数据平台介绍"，就重做。**
