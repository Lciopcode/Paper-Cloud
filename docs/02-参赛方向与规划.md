## 一、评分标准（全文要点提取，这是所有决策的依据）

### 1.1 六项一级指标（百分制）

| 一级指标 | 分值 | 官方主要评价内容 |
|---|---:|---|
| 选题价值与导向 | **10** | 问题/主题明确；**符合所报赛道要求**；价值导向正确；目标用户、应用对象、传播场景清楚 |
| **创新性与原创贡献** | **25** | 创意或方法有新意；与既有成果存在**实质差异**；学生团队原创构思、关键工作、新增贡献明确 |
| 技术实现与规范 | **25** | 技术路线合理；核心功能/流程完整；工程或制作质量可靠；**数据、版权、安全及技术使用规范** |
| **完成度与可验证性** | **20** | 成果完整；**能够运行、观看或有效展示**；材料与实际成果一致；**过程、测试和关键结论可核验** |
| 应用与传播价值 | **10** | 应用场景与受众明确；教育/文化/社会/产业/传播价值；可完善、推广、迭代 |
| 展示与答辩 | **10** | 材料清楚；团队熟悉作品与分工；能准确说明创新、技术、应用及 **AI 使用情况** |

### 1.2 四条决定性原文（逐字摘录）

| # | 原文 | 对我们的含义 |
|---|---|---|
| 1 | 「**数据可视化作品，重点评价数据来源、信息结构、视觉编码、可视化逻辑和信息传达效果**」 | ⭐ 五项我们全对上：数据来源=arXiv+OpenAlex+S2；信息结构=八层层级；视觉编码=三类边+十二级宇宙映射；可视化逻辑=双射编号；信息传达=整个作品 |
| 2 | 「**不得仅以算法复杂度、代码量或功能数量衡量创新水平**」 | ⚠️ **不要把"Feistel/八层/四层渲染"当卖点堆砌**。创新分只能靠观念+交互+应用 |
| 3 | 「**不得仅以创意说明、界面效果图、概念视频或静态展示替代应当实现的核心功能**」 | ✅ 我们天然占优：已有 41 单测 + 三套端到端自检。**必须交可运行的** |
| 4 | 「**使用生成式人工智能或其他人工智能工具不直接构成加分或扣分因素**」；需核验工具名称/环节/流程/参数、人工筛选与重构、**学生团队实质性贡献** | ✅ 放心用 AI；但**如实披露**，并说清"人做了什么" |

### 1.3 评审前置条件（不满足则不进量化评分）

- 参赛资格、内容导向、**原创性**、**知识产权**、材料可核验性
- 「第三方数据、模型、代码、字体、音乐、图像、视频等资源**来源及授权情况清楚**」
- 「**人工智能工具使用情况按照统一模板如实勾选和说明**」
- ⚠️ 「未按要求披露 AI 使用、伪造创作过程或明显缺少学生团队实质性贡献的，**不通过简单扣分处理，应按照竞赛纪律启动核查程序**」

### 1.4 奖项比例（最高控制比例，可空缺）

| 奖项 | 比例上限 |
|---|---:|
| 一等奖 | ≤ 5% |
| 二等奖 | ≤ 15% |
| 三等奖 | ≤ 20% |
| 合计 | ≤ 40% |

**同分处理顺序**：创新性与原创贡献 → 技术实现与规范 → 完成度与可验证性 → 展示与答辩。
**含义**：创新性是第一顺位，必须重点经营。

## 三、赛道选择：留到成品出来之后再定

### 3.1 为什么不现在定

赛道选择取决于**成品实际长成什么样**，而这件事现在还不知道。现在锁定，等于用猜测约束开发，改起来反而更贵。

**赛道选择推迟到最后，成本几乎为零**；而现在锁定、后来发现不合适，代价是返工。

### 3.2 三条赛道的"倒向条件"（做完之后拿成品去对号）

| 如果成品最后是这样的… | 就报 |
|---|---|
| 可视化做成了最大亮点（八层宇宙、三类关系边的视觉表达震撼，数据逻辑讲得清） | **① 数字艺术与可视化设计类** |
| GPU 语义层效果超出预期（能自动发现并命名研究方向、自动找出"同一路线"的论文） | **② AIGC 类数字创意作品创作** |
| 功能完整、稳定、交互流畅，但视觉不是最强项（或时间紧、只能保功能） | **③ 移动与网络应用开发类** |

### 3.3 开发期的"赛道无关"原则（这才是现在要守的）

为了让三条赛道都留有可能，开发期只需守住**四条共同要求**——它们对技术方案**没有冲突**：

| 共同要求 | 来自哪条赛道 | 对开发的约束 |
|---|---|---|
| **必须可运行** | ①（加分项）、②（Demo）、③（硬要求） | 不留纯概念模块，每个功能都要能点 |
| **必须有明确用户与场景** | ③（评审重点）、①（选题价值） | 界面上要能说清"给谁用、解决什么" |
| **必须能讲清 AI 的人机协同** | ②（评审重点） | 保留过程记录：聚类结果的人工校正、层级映射的设计决策 |
| **资源授权与 AI 披露要齐** | 三条共同的前置审查 | 随手记录来源，别等最后补 |

**结论：按这四条开发，赛道随时可换。** 具体的赛道对比留在下面，供将来对号使用。
